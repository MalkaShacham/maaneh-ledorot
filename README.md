# מענה לדורות | יקום הרבי

ארכיון/מודל אינטראקטיבי מבוסס־מקורות של תורתו, מענותיו והתיעוד ההיסטורי של הרבי מנחם מענדל שניאורסון.

> **מקור האמת של הפרויקט:** `PROJECT_CANON.md`.
> כל העבודה שנעשתה בעבר תחת "עדכון פרויקט מודל הרבי", "מענה לדורות" ו"יקום הרבי" מאוחדת מעתה לפרויקט אחד. מצב המדדים הקנוני נשמר ב־`data/project-state.json`.

## התקדמות הקורפוס

![מד התקדמות מענה לדורות](docs/progress-dashboard.svg)

הדשבורד נועד להציג **רק מה שקיים בפועל במאגר**, ולא הערכת היקף כללית. נתונים ישנים שאין להם עדיין רשומות מקור תומכות נשמרים כ־`legacy_pending_reconciliation` ואינם נספרים כ־Verified.

### משמעות השלבים

- **Discovered** — מקור/קורפוס אותר, אך טרם נבנה לו אינדקס פריטים מאומת.
- **Indexed** — נרשמו מטא־דאטה ומקור מדויק ברמת האינדוקס הרלוונטית.
- **Parsed** — תוכן המקור עובד למבנה נתונים בלי להשלים מידע חסר.
- **Linked** — נבנו קשרים מתועדים למקורות מקבילים/כפילויות/משפחות ראיות.
- **Verified** — הרשומה נבדקה מול מקור ישיר או עדות מקור מוסמכת ברמת הפריט.

## קבצי ליבה

- `PROJECT_CANON.md` — חזון, כללים, ארכיטקטורה וסדר עדיפויות.
- `data/project-state.json` — מצב קנוני, מדדים, חסמים ו־reconciliation.
- `data/research-foundation.json` — מודל הראיות, witnesses ורמות אפיסטמיות.
- `data/sources.json` — רישום קורפוסים ומקורות־על.
- `data/schemas/source-item.schema.json` — הסכמה המחייבת לרשומת מקור ברמת הפריט.
- `docs/progress-dashboard.svg` — תוצר חזותי של ההתקדמות.

> כלל יסוד: אין להציג הסקת AI, שחזור או השלמת הקשר כדברי הרבי. מקור חלקי נשאר מסומן כחלקי.
